# CASPER Docs

Design documents for **CASPER** (Cognitive Autonomous System for Personal Execution and Reasoning), a personal AI system I'm designing. The idea is an assistant that keeps long-term memory, plans multi-step work, and acts on your apps for you, instead of being a chatbot you have to keep re-explaining things to.

There's no code here yet, only the specs.
